Real work, in the open

Hand it a task. See every step.

Ask for a fix and Lumi searches the code, edits the files and runs the tests, showing each step as it goes, with every command and how long it took. When it's done, the changes are waiting on your branch for you to review.

Beyond code

Your files, documents and the web.

Turn a folder of receipts into a spreadsheet, draft a document or research a question in Lumi's built-in browser. Answers come back as charts, checklists and files you can open. On Windows, Lumi can also work in other apps for you.

Make it yours

Shape it around how you work.

Keep chats in projects with their own instructions. Teach Lumi reusable skills, create agents, and connect your tools with MCP connectors and plugins. Lumi remembers what matters across chats.

Away from your desk

Check in from your phone.

Pair the Android app or the mobile web app with your computer to follow progress, answer Lumi's questions and start new chats. Your computer does the work, so it needs to stay on and reachable. There's no native iPhone app; on iPhone, use the web app.

AI accounts and cost

A free app. Your AI account.

Lumi is free and open source under the MIT license. The AI comes from the account you connect, and that provider's plans, limits and charges apply.

  • GitHub CopilotBuilt in. Models and limits follow your Copilot plan.
  • ChatGPT planSign in with an eligible plan, such as Plus or Pro. No API key.
  • API providersOpenRouter, Microsoft Foundry and others, with your own key or sign-in, billed by the provider.
  • Local modelsOllama, LM Studio or another server you run, with a model that supports tools.

Whichever model you choose, the GitHub Copilot SDK runtime runs the agent. Chats stay on your computer; model requests and connectors send context to the services you use.

Questions

Is Lumi free?

Yes. Lumi is free and open source under the MIT license. AI usage isn't automatically free: Lumi uses the AI account you connect, and that provider's plans, limits and charges apply.

Which AI accounts can I use?

GitHub Copilot is built in. You can also sign in with an eligible ChatGPT plan, add API providers such as OpenRouter or Microsoft Foundry, or run local models with Ollama or LM Studio. Whichever model you pick, the GitHub Copilot SDK runtime runs the agent.

What can Lumi do on my computer, and how do approvals work?

Lumi can run commands, read and edit files, use its built-in browser and act through the connectors you add. You choose how much it does on its own: Full access (the default) runs actions without asking, Ask first asks before commands, file edits and connectors, and Auto-review (preview) lets GitHub Copilot's reviewer approve requests that match what you asked and asks you about the rest. Set it everywhere or per project, with rules for what's always allowed or never allowed.

Approvals decide whether an action runs; they aren't a sandbox. Keep backups and review what Lumi does.

Does the phone app need my computer?

Yes. The phone is a companion: Lumi runs on your computer, which needs to stay on, awake and reachable. Install the Android app from GitHub Releases, or use the mobile web app on iPhone or Android, then pair it in Lumi's Settings → Mobile. There's no native iOS app.

What's different on Windows, macOS and Linux?

Chats, projects, skills, agents, connectors and on-device dictation work on all three. Working in other apps' windows is Windows-only. The built-in browser uses WebView2 on Windows and the system's WebKit on macOS 14 or later and on Linux (WebKitGTK 4.1). macOS packages aren't signed or notarized yet.

Where are my chats stored?

On your computer. Model requests and connected tools still send context to the providers and services you use, so keeping chats locally isn't an offline or privacy guarantee.

Where do I report a bug or ask a question?

Open an issue on GitHub with the bug report or feature request form; search existing issues first and leave out private data. Report security concerns privately through the security policy.
